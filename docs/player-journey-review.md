# Player journey: review guide

The home keeps its study and analysis shortcuts and adds a second row with daily studies and the playable puzzle.
Changes are intentionally left uncommitted for review.

## Design direction

- Keep the existing typeface and compact two-column home layout; stack on mobile.
- Reuse white `#ffffff`, grey `#eeeeee`, text `#424242`, muted borders `#536390`, and link blue `#206a9d`. Dark mode follows existing theme variables, with `#6ab2e1` for links.
- Give the returning study one blue accent. Keep other destinations quiet and text led.
- Prioritize the next chess activity over study administration. Keep Read, Smart, Full lines and Sparring inside their study.

Desktop layout:

```text
Study chess       | Analyze your games
Your daily studies| Daily puzzle
```

Daily studies use the library’s existing Daily selection, with the most recently opened daily study first and the study with the most recorded active training time next. Those rows have quiet text cues; no usage cue is shown without recorded training. Desktop shows about six rows with scrolling. Mobile stacks the cards, shows four studies and links to the complete Daily list without a nested scroll area. Guest and empty-library cards provide one next action.

## Navigation layout

At widths of 1280 px and above, navigation occupies a fixed 176 px left column. The main links stay at the top; preferences and account stay below. Submenus expand within the scrollable navigation area, including in short windows. The existing top navigation remains between 901 and 1279 px, and the Menu button remains on smaller screens. Settings overlays cover the sidebar and content. Embedded board pages retain their full-width layout.

Review the breakpoint transitions, Escape and keyboard focus, settings dialogs, and the home, study and analysis pages with `assets/test/unit/site_navigation_browser.cjs`.

## Before and after

| Task | Before | After |
| --- | --- | --- |
| Return to training | Last study opens with the global practice preference. | Last study opens in its last selected mode; the existing home shortcut preserves its original text. |
| Home navigation | Study links and the daily puzzle. | Original labels and links retained; extra tactics and endgame links removed after review. |
| First study | Empty library says to create a study. | Empty library offers importing a repertoire or finding a public study. |
| Import | Metadata appears before PGN / Lichess inputs. | Import inputs appear first; existing metadata requirements remain. |

| Empty study search | No results and no guidance. | A message suggests another opening or importing a repertoire. |
| Analysis without studies | No repertoires, with no next action. | Contextual link to import a repertoire. |

## Review paths

1. Open home as a guest and as a returning player, in Spanish and English.
2. Open Sparring, switch to Read or Smart, leave the study, and return from home.
3. Reload after changing modes. A previous launch URL must not reset that choice.
4. Follow a chapter practice link from analysis. Its context must take precedence over the saved mode.
5. Open an empty library and the import form. Check that blank required fields are not marked red before interaction.
6. Solve an endgame and return to its catalogue. Continue practicing selects the first unsolved exercise.
7. Review at mobile and desktop widths, in light and dark mode, with keyboard navigation.
8. Move a study between Daily and Library, then reload home. Owned and saved public studies should follow that selection without duplicates; inaccessible private sources should never appear.

## Boundaries

The browser remembers study modes and endgame continuation on this device. Opening Sparring starts a new game; it does not restore a previous game's board. These preferences do not add account synchronization. Analysis still has existing English text beyond the new translated empty state. Description remains required by the study schema.

Browser fixtures and screenshots are generated by `assets/test/unit/player_journey_browser.cjs`; controller fixtures are exported with `LISTUDY_JOURNEY_PREVIEW` when running `player_journey_test.exs`.

### PGN tactics collections

Practice → Tactics now opens a separate tactics library using the existing study library components. Import selects “Tactics collection”; existing PGNs can be reclassified in Edit without losing progress. Collections use the same Full lines board, with comments/arrows hidden by default and separate preferences. Read and explicit hints remain available. Repertoire discovery, daily studies and game comparisons exclude these collections. The existing public puzzle catalogue remains accessible from this library while its player migration is deferred.
