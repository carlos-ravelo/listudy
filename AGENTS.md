# Product interface

- Keep implementation details out of the user interface. Do not add notices explaining storage locations, internal synchronization mechanisms, or technical architecture.
- Add interface text only when it helps the user perform an action or understand a relevant outcome. Do not add unsolicited technical explanations or informational filler.
- Keep technical diagnostics in logs or developer documentation. Show concise, actionable failure messages when users need them to recover.

# Repository language

- Write code identifiers, comments, commit messages, and developer documentation in English, regardless of the conversation language.
- Keep localized product text and translation resources in their intended language.
